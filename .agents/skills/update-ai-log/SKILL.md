# Update the AI log

1. Read `AGENTS.md` and `docs/AI_LOG.md`. If something is unclear, ask the student.
2. Find or create a section for the active milestone.
3. Propose an entry under `### Tools and tasks` with the tool, task, main prompt, generated result, and what the student kept, changed, or rejected. 
4. Ask whether the AI was wrong or produced poor code in this task. If so, include what was wrong, how it was noticed, and how it was fixed under `### Where the AI was wrong`.
5. Show the proposed entry and wait for the student's confirmation before saving it.
