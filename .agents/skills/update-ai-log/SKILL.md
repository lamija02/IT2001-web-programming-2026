# Update the AI log

1. Read `docs/AI_LOG.md`. Create it with the heading `# AI Log` if it does not exist.
2. Find or create a section for the active milestone, such as `## Milestone 1`.
3. Ask the student for any missing details about the tool and model, task, main prompt, generated result, and what they kept, changed, or rejected. Do not guess.
4. Add the task under `### Tools and tasks`. Quote a prompt only when its exact wording is available; otherwise label it as a prompt summary. Record the tool, model when known, task, result, and the student's review or changes.
5. Ask whether the AI was wrong or produced poor code in this task. If so, record what was wrong, how it was noticed, and how it was corrected under `### Where the AI was wrong`.
6. Never invent tools, models, prompts, results, or mistakes. If something is unclear, ask the student rather than filling in a plausible answer.
7. Show the proposed entry and wait for the student's confirmation before saving it.
